# ROOOMTECH AI Guard 法人向け導入

ROOOMTECH AI Guardは、生成AIや未許可アプリケーションから機密ファイルを保護するWindows向けセキュリティ製品です。

## 料金

法人・団体・業務目的での利用は有償・個別見積です。

見積は、端末数、導入拠点数、ポリシー設計、導入支援、運用支援、サポート条件などに応じて個別に設定します。

## 法人ライセンス

法人利用ではROOOMTECH株式会社が発行する署名付きBusinessライセンスが必要です。

ライセンスには以下を含みます。

- 契約先名
- 組織名
- ライセンスID
- 許諾端末数
- 利用開始日
- 有効期限（契約により無期限も可）
- ROOOMTECHの秘密鍵によるECDSA P-256署名

製品には検証用の公開鍵だけを含めます。ライセンスファイルを改変すると署名検証に失敗します。

## 導入メニュー

個別見積には、必要に応じて以下を含めます。

- Windows 11端末への導入
- 保護フォルダ設計
- 許可アプリケーション設計
- 既存セキュリティ製品との競合確認
- 監査ログ運用設計
- 展開手順書
- 管理者向け説明
- 更新・保守

## 販売時の説明

本製品は、指定した保護フォルダに対する未許可プロセスのファイルアクセスをWindowsのファイルI/O層で制御する製品です。

ChatGPT、Claude、Gemini等のサービス名を直接判定するのではなく、ブラウザ、Python、AIクライアント等の実行プロセスが許可されているかを基準に制御します。

ローカル管理者またはKernel権限を取得した攻撃者、許可済みアプリ自身からの情報転送、外部カメラ撮影などを完全に防ぐ製品ではありません。

## 正式一般配布版のリリースゲート

Kernel Driverを一般のWindows 11環境へ正式配布するには、Microsoft要件に従ったDriver署名と正式Minifilter Altitudeが必要です。

これらが未完了のRCパッケージは評価・開発用途として扱い、Kernel Driverを含まない場合はKernelレベルの強制保護は有効になりません。
