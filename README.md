# ROOOMTECH AI Guard

Windows 11向けの機密ファイル保護プロジェクトです。

目標は「AIに読めない形式へ変換する」ことではなく、保護対象ファイルへのアクセスをOS側で制御し、許可されていないプロセスからの読み取りを拒否することです。

## 現在の段階

MVP開発中です。初期版では以下を実装します。

- 保護フォルダのポリシー管理
- 許可アプリの管理
- アクセス判定ロジック
- 監査ログ
- Windows Minifilter Driver の土台
- Windows Service との連携土台

> 注意: 現時点は開発版です。ドライバー署名・耐タンパー・プロセス署名検証など、本番利用に必要な強化は今後追加します。
